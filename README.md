## 🔥 I Automate What's Costing You Money.

**DesiQuote** is an instant gig price calculator — visitors pick services,<br/>
toggle project modifiers, and hit WhatsApp with a pre-filled quote. Zero friction. Zero back-and-forth.

## ⚡ What It Does

| Feature | Description |

| 🧮 **Instant Quote Engine** | Select services → get an estimated cost in real-time |
| 🔀 **Project Modifiers** | Urgent delivery (2×), complex integrations (+50%), maintenance retainer |
| 💬 **One-Tap WhatsApp** | Pre-fills a message with selected services + cost estimate |
